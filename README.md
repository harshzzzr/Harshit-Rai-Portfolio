# Harshit Rai — Developer Portfolio

A modern, responsive personal portfolio built with **React**, **Vite**, and **Tailwind CSS**, powered by **Firebase** and deployed on **Vercel**.

🌐 **Live Demo:** [harshit-rai-portfolio.vercel.app](https://harshit-rai-portfolio.vercel.app)

---

## Overview

This repository contains the source code for the personal developer portfolio of **Harshit Rai**, a Computer Engineering student specializing in full-stack web engineering, C++ software systems, and algorithmic problem solving.

### Key Features

- **Project Showcase:** Detailed architectural overviews, problem-solution breakdowns, and live/source links for engineering projects.
- **Responsive Engineering UI:** Clean, accessible design optimized across all screen sizes (320px to 1920px) with zero layout shifts.
- **Theme Support:** Native dark and light mode toggle with smooth transitions and persistent user preference.
- **Contact & Inquiries:** Functional contact form integrated with Cloud Firestore for real-time message delivery.
- **Admin Management Console:** Secure administrative dashboard to manage portfolio data, project entries, and messages.
- **Performance & SEO:** Fast page loads via Vite code splitting, semantic HTML5, JSON-LD structured data, Open Graph previews, and automatic sitemap generation.
- **Production Edge Hosting:** Deployed on Vercel with Single Page Application (SPA) routing, edge caching, and security headers.

---

## Tech Stack

- **Frontend:** React 18, React Router 6, Tailwind CSS, Lucide React
- **Build System:** Vite 6
- **Backend & Cloud:** Firebase (Firestore, Storage, Authentication)
- **Deployment:** Vercel

## Getting Started

### Prerequisites

- [Node.js](https://nodejs.org/) (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/harshzzzr/Harshit-Rai-Portfolio.git
   cd Harshit-Rai-Portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Configure Environment Variables:**
   Copy `.env.example` to `.env` and fill in your Firebase configuration keys:
   ```bash
   cp .env.example .env
   ```

4. **Start the local development server:**
   ```bash
   npm run dev
   ```
   Open `http://localhost:5173` in your browser.

5. **Build for production:**
   ```bash
   npm run build
   ```
   The compiled assets will be output to the `dist/` directory.
